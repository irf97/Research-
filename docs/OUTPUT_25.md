# Output 25 — Master Domain Model, Not Master Spreadsheet

The programme should not be organized around courses or documents. Courses, university briefs, PDFs, CVs and Excel workbooks are projections of one canonical research/programme model.

## Canonical orientation

Research Programme
→ Research Agendas
→ Research Questions
→ Hypotheses
→ Experiments
→ Capabilities
→ Projects
→ Evidence
→ Decisions / Risks / Tasks / Opportunities

Universities, labs and courses attach to the research/capability graph. They are resources that help close a capability gap or enable an experiment.

## Three current programme layers

### LivingMesh — Infrastructure
How should physical reality become safely computational and locally actionable?

### Proximity Ecology — Emergence
What social/cultural/economic dynamics appear when discovery and competition are locality-constrained?

### Spontaneity Interface — Interaction Grammar
How should humans perceive and act within that world with minimal cognitive burden and minimal unnecessary screen time?

These are current agendas, not hard-coded permanent software categories.

## Projects are domain experiments

Football United, Spectrum and Grind are not the conceptual hierarchy. They instantiate one or more agendas.

### Football United
- LivingMesh: fields, nodes, proximity, authority
- Proximity Ecology: local competition, scouting, talent, cultural styles
- Spontaneity Interface: discover → commit → play → reflect

### Grind
- LivingMesh: people, organizations, needs, resources
- Proximity Ecology: local capability networks
- Spontaneity Interface: need → team → project → execution

### Spectrum
- LivingMesh: contextual personas / state
- Proximity Ecology: social/contextual discovery
- Spontaneity Interface: personal relevance and spontaneous interaction

## Capability graph

Every capability should connect:

current capability
→ evidence
→ desired level
→ gap
→ course/lab/project that may close it
→ future experiment/artifact that proves the capability

The system should answer why one university or course is strategically valuable based on an explicit capability/research path.

## Evidence as first-class truth discipline

Ambitious statements should trace to actual evidence: code, manuscript, prototype, tests, experiments, publications, datasets, videos and external validation.

One canonical graph should be able to generate different outputs for different audiences without duplicating truth.

## Time as a projection

The same canonical graph can project into an MSc trajectory:

foundational course
→ prototype
→ embodied/proximity experiment
→ exchange lab
→ Research Topics
→ formal thesis study
→ publication / demonstrator

Anything disconnected from this trajectory should be inspectable.

## Core conceptual change

> Do not build a master spreadsheet. Build a master domain model.

Then Excel, PDF, website, thesis plan, exchange proposal and AI context become audience-specific projections of the same canonical state.
