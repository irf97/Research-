# Output 24 — Interaction Grammar / Spontaneity Interface

The third thesis layer is the human interaction grammar for a proximity-governed world.

## Core proposition

LivingMesh answers how physical reality becomes locally readable and actionable. Proximity Ecology asks what social, cultural and competitive dynamics emerge when discovery is local. The Spontaneity Interface asks:

> What interaction grammar makes a dynamic proximity-governed physical world understandable and attractive enough that people spontaneously act within it?

The interface is not decoration. It is the projection layer that turns rich structured world-state into minimal, relevant human possibilities.

## General interaction loop

Intent
→ Nearby Reveal
→ Possibility
→ Commitment
→ Session Formation
→ Real-World Execution
→ Reflection
→ Dissolution

The goal is to reduce the distance between:

> something could happen

and

> people are now doing it.

The successful interface should often get the user out of the interface and into reality.

## Architectural chain

LivingMesh
→ knows what exists

Proximity
→ determines what is physically/contextually reachable

Spectrum / persona / context
→ determines what may be relevant to this person now

Spontaneity Interface
→ reveals the smallest useful possibility

Session Engine
→ converts possibility into coordinated reality

Execution
→ people leave the interface and act

Reflection / local memory
→ the world learns

Expiry
→ temporary structures disappear

## Key design paradox

Maximum infrastructural sophistication underneath; minimum cognitive burden above.

Underlying complexity may include authority, personas, proximity, expiry, resources, reputation, AI interpretations, sessions, permissions, local governance, devices and multi-agent state.

The human projection should feel closer to:

> Here. Now. Possible. Join.

## Comparative HCI experiment

Compare three interface paradigms:

### Directory UI
Search / filter / list.

### Feed UI
A centralized recommendation algorithm continuously surfaces opportunities.

### Proximity-World UI
Movement, place, context, intent and commitment progressively reveal possibilities.

Candidate metrics:

- time to action
- screen time before action
- planning messages/actions required
- number of successful spontaneous sessions
- perceived serendipity
- sense of exploration
- agency
- comprehension of why something appeared
- social comfort
- repeat physical participation
- diversity of discovered people/places
- ability to understand local state without instruction

## Football United instantiation

Do not begin with `Search players`.

Possible progressive disclosure:

far away
→ field / scene exists

closer
→ match forming, style, level, demand

relevant proximity
→ players, teams, local culture, roles

physical participation/context
→ richer history, contextual statistics, compatible evaluators

scouting presence
→ permitted local scouting projections become available

The existing Football United session flow is conceptually:

discover field
→ join queue
→ lobby
→ nearby commitment
→ physical check-in
→ match
→ compacted summary

## Grind instantiation

Need or project opportunity
→ nearby/reachable capabilities
→ potential collaborators
→ proposed team
→ project scope
→ resources
→ commitment
→ temporary project session
→ execution
→ evidence/outcome
→ dissolution

The interface should reduce the distance between an organization/student problem and a real team doing the work.

## Spectrum instantiation

Spectrum may act as a relevance layer between the vast set of reachable possibilities and what should surface for this person now.

The system should not expose everything. It should make the local world personally legible without turning it into a centralized feed.

## Generalization question
